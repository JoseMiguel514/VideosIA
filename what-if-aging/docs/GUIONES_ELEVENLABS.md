# Guiones para ElevenLabs

Cada video tiene dos versiones del guion:
- `.txt`: texto corrido, listo para pegar en ElevenLabs (un párrafo por escena).
- `_por_escena.txt`: el mismo texto con el ID de cada escena, por si quieres generar un audio por escena (nómbralos `p01.mp3`, `p02.mp3`, …) para resincronizar la animación.

Notas de pronunciación para ElevenLabs:
- "A P U" → escríbelo "A-P-U" si la voz lo lee raro.
- "Galunggung" se pronuncia "Gah-loong-goong"; "Gimli" = "Gim-lee"; "Dement" = "Deh-MENT"; "Turritopsis dohrnii" = "Tur-ih-TOP-sis DOOR-nee-eye".
